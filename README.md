# 📘 Case Study: YOSMITE – Tourism Website

YOSMITE is a tourism website interface inspired by a national park experience in California.  
The project focuses on building a visually structured landing experience using HTML, CSS, and JS, emphasizing layout composition, visual hierarchy, and clean UI presentation.

This project demonstrates frontend fundamentals and static UI implementation without relying on frameworks.

---

## 🔗 Live Demo

[YOSMITE](https://yosmite-website.vercel.app/)

---

## 📌 Project Overview

The goal of this project was to create a tourism-style website that presents destinations and information through a visually engaging layout.

Core Focus:

- Clear content sections and layout organization
- Image-driven design suitable for tourism websites
- Consistent typography and spacing
- Simple navigation flow
- Structured page composition using pure CSS

This project represents an early-stage UI implementation focused on layout and visual structure.

---

## ✨ Key Features

- Hero section with visual emphasis
- Section-based page structure
- Image-focused content presentation
- Clean typography and spacing
- Static navigation layout
- Lightweight implementation

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (Basic interactions)

---

## 🧩 Development Approach

The project focuses on core UI principles:

- Semantic HTML structure
- Separation between content and styling
- Organized CSS for layout control
- Visual hierarchy through spacing and imagery
- Simple and readable code structure

The website was intentionally built without frameworks to strengthen frontend layout fundamentals.
